# WPS Excel 图片兼容

支持导入 WPS 保存的 `.xlsx`，以及普通 `.xls` 工艺文件。`.et` / `.ett` 不在V1支持范围，
需要在WPS中另存为`.xlsx`。不能据此承诺所有WPS专有对象与所有版本完全兼容。

## 已实现

WPS把部分图片存为 `DISPIMG("图片ID",1)` 公式，图片索引位于 `xl/cellimages.xml`，
与普通 DrawingML 插图不同。当前部署的LibreOffice原始加载流程会把该公式作为文字输出，缺少照片。
参见 [WPS官方兼容说明](https://www.wps.cn/learning/question/detail/id/335117)。

兼容层在隔离转换副本中读取ID、工作表、单元格/合并范围和嵌入图片：

- 接受字面量 `DISPIMG("ID",1)`、`_xlfn.DISPIMG(...)` 及前导`@`。
- 仅使用文件内的PNG/JPEG；先完整解码验证，再以原比例居中放入对应单元格范围。
- 只清除这些已解析图片的占位公式，保留样式、表格、合并、打印设置和其他图形。
- WPS副本在LibreOffice内允许内容修改，仅用于PDF导出，从不保存回Excel原件。
  无WPS图片的文档继续ReadOnly加载。宏、链接更新始终禁用，worker仍然断网。
- 原件和已发布版本保持不变；旧资产不原地重新生成，修复后重新上传生成新资产。
- 在warnings中显示识别/还原结果，在metadata中保存`wps_cell_images_restored`。
- 图片引用丢失、外部链接、重复ID、非PNG/JPEG、损坏/过大图片或不支持的动态/复合/共享公式，
  转换明确失败，不能悄悄漏图后发布。隐藏行列等无法确定有效尺寸时也明确失败。

PDF导出使用无损图片压缩、不主动降低图片分辨率。默认按RENDER_DPI生成原打印分页PNG。
可明确选择「16:9 整表单页」：每张可见表一页，忽略打印区域，PNG等比居中到1920×1080白色画布。
隐藏工作表在临时PDF中过滤后才生成可下载文件。模式、实际页数和输出尺寸持久化，队列恢复保留。
两种模式均不修改Excel原件或已发布文件；新转换会在内存中忽略下述明确零尺寸残留对象。

### 推荐的WPS PDF路径

中心支持直接上传`.pdf`，保留已有页面后生成1920×1080播放图片，不经过LibreOffice的Excel导入器。
管理员先在WPS选指导书打印区域、横向、缩放1页宽×1页高，确认打印预览无黄色图形重叠后导出PDF。
每张工作表可各一页；多页PDF不会在中心重新排版或合并。PDF和分页预览确认后再发布。
这提供绕过其他Excel图形兼容问题的路径；零尺寸残留对象已有下面的专项修复，不代表任意浮动图形都保真。
尚未收到用户从WPS导出的真实PDF，因此实际图形保真效果仍待该PDF验证。
